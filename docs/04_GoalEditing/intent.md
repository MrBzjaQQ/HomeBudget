# Intent: GoalEditing

## Намерение
Пользователь должен иметь возможность исправлять сведения о своих финансовых целях на странице «Финансовые цели». Это позволит поддерживать цели актуальными, если изменились планы или при их создании были допущены ошибки.

Редактирование должно быть доступно именно в разделе управления финансовыми целями. Раздел аналитики предназначен для просмотра результатов и не должен предоставлять возможность изменять цели.

## Пользователь
Пользователь приложения, который ведёт финансовые цели и хочет обновить их сведения на странице «Финансовые цели» либо просматривать аналитику без риска случайно изменить цель.

## Результат (измеримо)
- Пользователь сможет изменить сведения существующей финансовой цели со страницы «Финансовые цели».
- Пользователь сможет просматривать финансовые цели в разделе аналитики без доступных там действий редактирования.

## Ограничения и «не делаем»
- Не добавляем возможность редактирования финансовых целей в разделе аналитики.
- Не меняем сценарии просмотра финансовых целей и аналитики, кроме необходимого для разделения доступных действий.

## Открытые вопросы
- Какие именно сведения финансовой цели пользователь должен иметь возможность редактировать?
