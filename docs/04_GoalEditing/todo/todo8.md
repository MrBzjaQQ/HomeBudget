## Контекст
Пользователь попросил заменить текст «Редактировать» на кнопке цели иконкой карандаша, чтобы она сочеталась с соседней кнопкой-иконкой удаления, и проверить отображение компонента на мобильном экране. Относится к FR-1 и FR-7 исходной задачи. Текущая кнопка и строка карточки: `frontend/src/app/features/goals/goals.component.html:112-136`; стили иконки: `frontend/src/app/features/goals/goals.component.css:24-45`. На странице накоплений уже используется символ карандаша `✎`: `frontend/src/app/features/savings/savings.component.html:85-92`.

## Что сделать
1. Заменить видимый текст кнопки редактирования финансовой цели на иконку карандаша (предпочтительно существующий в приложении символ `✎`), сохранив `type="button"`, handler `startEdit(g)` и disabled-поведение.
2. Обеспечить понятную доступность иконки без видимого текста: добавить доступное имя «Редактировать цель» и при необходимости title; иконка должна быть скрыта от screen reader, чтобы не дублировать имя.
3. Привести кнопку к визуальному виду/размеру соседней кнопки удаления и сохранить удобную touch target на мобильном (не меньше примерно 40×40 CSS px на узком экране; можно адаптировать только mobile-стили).
4. Проверить responsive-компоновку карточки цели на узком viewport: длинное название и иконки управления не должны перекрывать друг друга или создавать горизонтальный overflow; данные и прогресс должны оставаться читаемыми. Внести минимальные локальные адаптивные правки, если проверка выявит проблему.

## Ограничения
- Изменять только `frontend/src/app/features/goals/goals.component.html` и при необходимости `.css`.
- Не менять сценарии редактирования/удаления, API, аналитику или бизнес-логику.
- Сохранять визуальную/доступную цель для кнопок и работу на desktop.

## Результат (критерий приёмки)
- [ ] На кнопке редактирования показан карандаш вместо текста, с доступным именем «Редактировать цель».
- [ ] Обе иконки управления выровнены; на узком экране имеют достаточный touch target.
- [ ] Карточка не имеет горизонтального overflow при длинном названии, кнопки и данные не перекрываются; `npm run build` в `frontend` проходит.
