## Контекст
Финальная браузерная проверка иконки edit и responsive-компоновки страницы «Финансовые цели». Требование пользователя: карандаш вместо текста и корректное отображение на мобильном. Реализация — `frontend/src/app/features/goals/goals.component.html/css`; приемочные критерии в `todo8.md`.

## Что сделать
1. После пересборки сервиса проверить на desktop: рядом с удалением показана иконка карандаша, нет текста «Редактировать», доступное имя кнопки корректно, клик открывает редактирование.
2. Эмулировать мобильный viewport (например, 375×812 CSS px) и проверить страницу `/goals`: заголовок/длинное название цели, edit/delete-кнопки, показатели и прогресс не обрезаются наложением; страница не имеет горизонтального overflow; touch targets пригодны для нажатия.
3. Проверить изменение viewport на другой узкий размер (например, 320 px) либо обозначить ограничения, если они есть; проверить переход в режим редактирования на mobile.
4. При UI-проверке не оставлять тестовые изменения данных; если для проверки достаточно статической страницы, не менять данные.
