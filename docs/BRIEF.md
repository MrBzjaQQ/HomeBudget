# BRIEF: docs

## Назначение

Документация и артефакты разработки: продуктовые ТЗ (спецификации фич) и папки задач Spec-Driven-Design пайплайна (`intent.md` → `spec.md` → `todo/*.md`).

## Дерево

```
docs/
├── ТЗ_ Домашний бюджет — учёт доходов и расходов (Angular + .NET + PostgreSQL).md
│       # базовое ТЗ приложения (фундамент: журнал, категории, пользователи, авторизация)
├── ТЗ_ Бюджет — плановые расходы по категориям.md
│       # ТЗ фичи «Плановый бюджет» (план/факт по категориям на месяц)
├── ТЗ_ Бюджет — накопления.md
│       # ТЗ фичи «Накопления» (счета, помесячные записи, сводка 12 мес.)
└── 01_Refactoring/
    └── ТЗ_Рефакторинг.md
            # текущая задача: рефакторинг компонентов Angular, Clean Architecture backend,
            # BRIEF.md, агенты и навыки OpenCode
```

## Правила

- Номер задачи — двузначный префикс имени папки: `NN_КраткоеНазвание/`.
- Внутри папки задачи (создаётся навыком `prepare-intent` / `prepare-specification` / `prepare-todo`):
  - `intent.md` — бизнес-описание намерения (на русском);
  - `spec.md` — техническая спецификация: что делать/не делать, ограничения, варианты, решения,
    дерево проекта, какие файлы меняются, какие тесты, граф зависимости задач;
  - `todo/todoN.md` — атомарные подзадачи с результатом выполнения (заполняет `manage-development`).
- Исторические ТЗ (файлы `ТЗ_*.md` в корне папки) — не изменять: это зафиксированные требования.
- Новые требования/фичи — только новой папкой `NN_...` с пайплайном intent → spec → todo.

## Навигация

- Выше: `../BRIEF.md` (корень проекта).
- Артефакты генерируют навыки OpenCode: `prepare-intent`, `prepare-specification`, `prepare-todo`, `manage-development` (`.opencode/skills/`).
